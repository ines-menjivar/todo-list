# Todo List App

A simple React application built with Vite. This project demonstrates basic React setup, component structure, and development workflow.

## Installation

1. Clone the repository:
   git clone https://github.com/ines-menjivar/todo-list.git

2. Navigate into the project folder:
   cd todo-list

3. Install dependencies:
   npm install

## Running the Development Server

Start the Vite dev server:
npm run dev

Then open your browser and go to:
http://localhost:5173
